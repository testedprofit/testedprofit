Finding your device IP

The row at the top is the public address for this browser. Each device at home also has a private address. A public address is on the internet side of the router. A private address stays inside the house and is not routed on the public internet, so the same private numbers repeat in many homes.

RFC 1918 reserves 10.0.0.0 through 10.255.255.255, 172.16.0.0 through 172.31.255.255, and 192.168.0.0 through 192.168.255.255. Day to day that is 10.x.x.x, 192.168.x.x, and the 172.16 through 172.31 block. Websites do not see 192.168.1.42. They see the public address from this lookup. The router translates between the two.

The router's local address is the gateway. Many home units use 192.168.1.1, 192.168.0.1, or 10.0.0.1. The reading on your device wins if yours differs. On Windows, run ipconfig. IPv4 Address is the private address and Default Gateway is the router. On a Mac, System Settings, Network, Wi-Fi, Details, TCP/IP lists both. Older macOS uses System Preferences. If ipconfig getifaddr en0 is blank, use that TCP/IP pane.

Type the gateway into a browser while you are joined to that network. The admin page lists connected clients, which is how you find a printer or an unknown device. A printer often keeps one private address if you reserve it in the DHCP table or set it on the printer. If a row looks unfamiliar, match it to a sticker or a screen, or switch the device off and see which row drops. Leave remote administration off unless you need it, and do not forward a port toward a device you cannot name.

Finding your IP on phone and Wi-Fi

Phone settings show the private address on the Wi-Fi you joined. This page, opened in the phone browser, shows the public address of that same Wi-Fi. They are not interchangeable. A support agent who asks for the number in Wi-Fi settings is asking for the private one.

On an iPhone: Settings, Wi-Fi, the info button. IP Address is private. Router is the gateway. Open this page in Safari for the public address, or turn Wi-Fi off and reload for the carrier address.

On a Pixel: Settings, Network and internet, Internet, the gear beside Wi-Fi. On many Samsung phones: Settings, Connections, Wi-Fi, the gear, View more. That address is private. Search Settings for IP address if the labels differ.

Cafe Wi-Fi uses the venue's public address, not your home one. Reload this page when you switch networks. A dynamic home address may come back the same, or the provider may hand out another.

Location and accuracy

The city, region, postal code, time zone, and coordinates come from records about who holds that block of addresses. They are not a GPS reading from the phone, and they are not a street. Registries usually place a block near the provider, often in a city and sometimes only in a state or country. Extra decimal places on the pin do not make it a building.

Mobile traffic can appear in another city because the carrier gateway is there. A VPN shows the server's city. Some providers put many customers behind one public IPv4 address, called carrier-grade NAT, so the pin describes a shared gateway rather than one house. The map on this page is labeled approximate for that reason. If the pin is off, read why the location is wrong in the questions below.

IPv4 and IPv6

IPv4 is four numbers from 0 to 255, separated by dots. The documentation shape 203.0.113.10 shows the pattern without pointing at a real host. About 4.3 billion combinations exist, which is not enough for every phone and server, so networks share IPv4 widely.

IPv6 is 128 bits, written as hexadecimal groups separated by colons. RFC 8200 is the current specification. Many networks run both at once. An address starting with fe80 is link-local and is not the public address a website sees. This checker fills the family the lookup returned. The other row says Not detected when that call did not include it.

Safety, privacy, and what others can see

Your provider routes the traffic and can see which servers you contact. On a normal HTTPS site the page text is encrypted. The site name is often still visible while the connection starts. If you use the provider's DNS, the provider also sees the names you look up. Encrypted DNS sends those lookups to the resolver you chose instead.

A website sees the public IP, the time, the pages you open there, and headers such as the user agent. It does not see a 192.168 or 10.x address, the other devices at home, or a street hidden in the number. If you sign in, the site can store the public address beside the account. That record is the site's log, not a house number inside the IP.

A user agent is text the browser sends with a request. It names the browser family and the operating system, such as Chrome on Windows or Safari on an iPhone. It is not an IP address and not a login. Sites use it to pick a layout. The string this browser is sending is here: Detecting the user agent. Browsers can shorten it, and a script can send another one, so it only hints at the kind of device.

You can show websites a different public address, and each method has a cost. A router restart sometimes changes a dynamic address and sometimes does not, and it does not encrypt anything. A VPN shows the server's address. The path to that server is encrypted, which helps on cafe Wi-Fi, but the operator can see destinations and some sites block those ranges. A proxy forwards one app and may not encrypt the hop. Tor shows the exit relay, more slowly, and an exit can read traffic that is not HTTPS. Mobile data swaps the home address for the carrier's. None of these is a product offered on this page.

Do not paste a public address beside your name. Keep the router admin page and old camera ports off the internet. The private address is for jobs on your own Wi-Fi, such as a printer. If a caller asks you to read a number aloud to prove an account, use the phone number on the card or the bill.

Understanding your IP address

An IP address is the number a network uses to deliver data to a device. IP stands for Internet Protocol. It belongs to the connection, so another Wi-Fi network means another address. The rows above are the public IPv4 and IPv6 values from this lookup. One may say Not detected. Details appear only for fields the service sent. The private address in device settings is how your own devices find each other, not a substitute for the lookup.

Why your IP changes

A dynamic address is leased and can change when the lease ends. Home routers usually get a dynamic public address. A static address is set to stay, such as a DHCP reservation for a printer, or a public address the provider agrees to keep. Most homes do not have a static public address.

Restarting the router asks for a new lease. Unplug the modem and router, wait a minute, and plug the modem in first. You might get a new public IP or the same one again. A shared carrier address stays shared.

Mobile networks change the visible address more often. The phone moves between towers, Wi-Fi, and carrier gateways. Reload after you leave home Wi-Fi. The city in the result can move with the gateway even on a short walk.

Questions

Why is my location wrong?

The city and coordinates describe the provider network block, not a GPS reading and not your street. A mobile gateway, a shared address, or a VPN can place the pin in another city.

What is my IP address?

It is the public address of the connection this browser is using. The IPv4 or IPv6 row shows it after the lookup. It is not the 192.168 or 10.x address in your phone Wi-Fi settings.

What is my IP?

The same public address. What is my IP and what is my IP address are one question, and this checker answers it for the browser you have open.

How does an IP lookup work?

The page asks the lookup service which public address reached it. The service returns that address plus the provider, the network location, and the other fields it has. The browser fills the rows. No account is required.

What is the difference between a public and a private IP?

A public IP is the address on the internet side of your router. A private IP, such as 192.168.x.x or 10.x.x.x, is used only inside your home or office. Websites see the public one.

Is it safe to share my IP address?

A public IP is not a password and it does not reveal your street by itself. Do not post it beside your name. Do not read it to a caller who claims to be your bank. Keep the router admin page off the public internet.

How do I find my IP address on my phone?

Wi-Fi settings on an iPhone or Android show the private address on that network. This page shows the public address. Turn Wi-Fi off and reload if you want the address your carrier is using.

Can I hide my IP address?

A VPN, a proxy, or Tor can show websites a different public address. Mobile data shows the carrier address instead of your home router. Restarting the router sometimes changes a dynamic home address and sometimes does not. This checker does not sell a VPN.
