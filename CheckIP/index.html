What an IP address is

An IP address is the number a network uses to deliver data to a device. IP stands for Internet Protocol. The reply to a page load comes back to that number. It belongs to the connection, so joining another Wi-Fi network changes it.

NetBeacon, the IP lookup above, shows the public address that reached the internet from this browser, plus the provider and a rough network location. Websites see that public address. A phone's Wi-Fi settings usually show the private address used only on the local network.

Public and private IP addresses

Private addresses stay on local networks and are not routed on the public internet, so the same numbers repeat in many homes. RFC 1918 reserves 10.0.0.0 through 10.255.255.255, 172.16.0.0 through 172.31.255.255, and 192.168.0.0 through 192.168.255.255. Day to day that is 10.x.x.x, 192.168.x.x, and the 172.16 through 172.31 block.

A home router stands in the middle. Inside, it often uses 192.168.0.1, 192.168.1.1, or 10.0.0.1 and gives each device a private address. Outside, it uses a public address from the provider, sometimes shared with other customers. It presents that public address when you open a site, so the site does not learn that the laptop is 192.168.1.42.

Some carriers put many customers behind one public IPv4 address, called carrier-grade NAT. This page still shows the address websites see, and it may belong to a group rather than one house.

IPv4 and IPv6

IPv4 is four numbers from 0 to 255, separated by dots, as in the documentation example 203.0.113.10. About 4.3 billion combinations exist, so networks share them heavily.

IPv6 is 128 bits, written as hexadecimal groups separated by colons. RFC 8200 is the current specification. Many networks run both at once, called dual stack. An address starting with fe80 is link-local and stays on the local link. This checker shows the address the lookup saw, whether that is IPv4 or the longer IPv6 form.

Why the location is only approximate

The city, region, and coordinates describe the network block, not a GPS fix and not a street. Records usually place the block near the provider, often a city and sometimes only a state or country. Mobile traffic can appear in another city because the carrier gateway is there, and a VPN shows the server's city. Extra decimal places do not make the pin a building.

What your provider and websites can see

The provider routes your traffic and can see which servers you contact. On HTTPS the page text is encrypted, though the site name is often visible as the connection starts. The provider's DNS also sees the names you look up. Encrypted DNS sends those lookups to the resolver you chose.

A website sees the public IP, the time, the pages you open there, and headers such as the user agent. It does not see a 192.168 or 10.x address or a street hidden in the number. If you sign in, the site can store that public address beside the account.

How to find your IP on each device

The figure at the top is the public address. These steps find the private address and the router's local address. Menu names vary by version.

Windows. Run ipconfig in Command Prompt. IPv4 Address on the active adapter is private, and Default Gateway is the router. Settings, Network and internet, then hardware properties, shows the same IPv4 address.

Mac. System Settings, Network, Wi-Fi, Details, TCP/IP lists the private address and the Router. Older macOS uses System Preferences. In Terminal, ipconfig getifaddr en0 is Wi-Fi on many Macs. If it is blank, use the TCP/IP pane.

iPhone. Settings, Wi-Fi, the info button, then IP Address is the private number, and Router is the gateway. This page shows the public address. Turn Wi-Fi off and reload for the carrier address.

Android. On a Pixel: Settings, Network and internet, Internet, the gear beside Wi-Fi. On many Samsung phones: Settings, Connections, Wi-Fi, the gear, View more. That address is private. Search Settings for IP address if the labels differ.

Router. Type the gateway into a browser on a device joined to that network. 192.168.0.1, 192.168.1.1, and 10.0.0.1 are common. The admin page can show the provider's internet address. Open it from inside the network, and leave remote administration off unless you need it.

Static and dynamic IP addresses

A dynamic address is leased and can change. Home routers usually get a dynamic public address, and laptops get a dynamic private one from the router. A static address is set to stay. Reserve one in the router's DHCP list when a printer should keep its number. A static public address lets a server stay findable. Most homes do not have one.

How to change or hide your IP

A restart may swap one dynamic public address for another from the same provider. A VPN, proxy, or Tor shows websites a different network. The private address inside the house is a separate matter.

Restart the router. Unplug the modem and router, wait a minute, then plug the modem in first. You might get a new public IP or the same one again. Nothing is encrypted, and a shared address stays shared.

VPN. Sites see the VPN server's address, and the path to that server is encrypted. The operator can see destinations, so the logging policy matters. Some sites block VPN ranges, speed often drops, and a free service may log you or show ads.

Proxy. One app is forwarded and the site sees the proxy. Many proxies do not encrypt the hop, and a web proxy can read pages it fetches. Use one only if you know the operator.

Tor. Traffic crosses several relays, and the site sees the exit relay. It is slower, some sites block those exits, and an exit can read traffic that is not HTTPS.

Mobile data. Turn Wi-Fi off and reload to use the carrier address instead of the home router. That spends cellular data. The carrier still knows the line, and the city shown may be a gateway city.

What a user agent is

A user agent is text the browser sends with a request. It names the browser family and the operating system, such as Chrome on Windows or Safari on an iPhone. It is not an IP address. Sites use it to pick a layout. The panel under the checker shows this browser's string. It can be shortened or replaced, so it is only a hint about the device.

Is it safe to share my IP?

A public IP names the network that reached the internet. It is not your street, a password, or the laptop's private address. Do not post it beside your name. Anyone can try to open services on a public address, so keep the router admin page, file shares, and old camera ports off the internet. Forward a port only when a device must be reached from outside.

Use the private address for jobs on your own Wi-Fi, such as a printer. A stranger cannot deliver traffic to 192.168.1.20 inside the house. If someone asks you to read a number aloud to prove an account, call the number on the card or the bill.

Questions

What is my IP address?

It is the public address of the connection you are using, shown at the top of this page once the lookup returns. That number is what websites see. It is not the 192.168 or 10.x address printed in your phone Wi-Fi settings.

What is my IP?

The same public address. What is my IP and what is my IP address are one question, and this checker answers it for the browser you have open.

How does an IP lookup work?

The page asks a lookup service which public address reached it. The service returns that address plus the provider and an approximate network location. Your browser fills in the boxes. Nothing is typed in, and no account is required.

What is the difference between a public and a private IP?

A public IP is the address on the internet side of your router, assigned or shared by your provider. A private IP, such as 192.168.x.x or 10.x.x.x, is used only inside your home or office network. Websites see the public one.

Does my IP address show my home address?

No. The city and coordinates are an estimate for the network block, usually near the provider or a gateway. They are not a GPS fix and they are not your street address.

Is it safe to share my IP address?

A public IP is not a password, and it does not reveal your street by itself. Do not post it beside your name. Do not read it to a caller who claims to be your bank. Keep your router admin page off the public internet.

How do I find my IP address on my phone?

The Wi-Fi settings on an iPhone or Android show the private address on that network. This page shows the public address. Turn Wi-Fi off and reload if you want the address your carrier is using.

Can I hide my IP address?

A VPN, a proxy, or Tor can show a different public address to websites. Mobile data shows the carrier address instead of your home router. Restarting the router sometimes changes a dynamic home address and sometimes does not.
