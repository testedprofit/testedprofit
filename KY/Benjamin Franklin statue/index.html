Benjamin Franklin statue

Wikipedia's article on Felix de Weldon lists, among his works, a 1973 Benjamin Franklin at the Louisville Public Library in Louisville, Kentucky. The same list has a separate 1973 line for General George Rogers Clark in Louisville. This guide uses that list for the Franklin sculpture. It does not add a street address, a pose, a cane, a treaty tablet, a pedestal inscription, or a set of visiting hours, because none of those points appear in the article that opened.

A Clio entry for a Louisville Franklin statue returned 403 on this check, so Clio is named and not linked, and nothing from that closed page is repeated. A Louisville Free Public Library locations URL checked for this pass returned 404, so it is not linked either. Until a library or city page opens with a doorway, a height, or a material, those details stay off this guide. The existing URL is unchanged.

The Clark entry on the same list is not this sculpture. Louisville Downtown Partnership has its own listing for a George Rogers Clark by Felix W. de Weldon at Riverfront Plaza/Belvedere, and that record is written up on the Clark guide. Both list lines are dated 1973. They name different subjects, and only the Clark listing that opened includes a street address.

The Clark record is on the George Rogers Clark guide.
